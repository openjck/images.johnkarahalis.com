These are hosted images that are used on my blog. Images for other purposes may
be added in the future. All images are hosted behind [Netlify Image
CDN](https://docs.netlify.com/build/image-cdn/overview/), which compresses
images on-the-fly as needed.

Original images are stored in directories named _original_ in part because it is
more explicit and I will therefore be less likely to embed original images
accidentally.
